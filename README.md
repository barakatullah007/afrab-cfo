# Afrab CFO

> Your Personal AI CFO

Afrab CFO is an AI-native Financial Operating System that helps users make confident financial decisions through explainable AI, financial intelligence, and proactive coaching.

## Vision

Help people stop wondering:

"Where did my salary go?"

Instead, help them confidently answer:

"I know exactly where my money is, what I can safely spend, and what I should do next."

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Backend
- FastAPI
- Python 3.14
- SQLAlchemy
- PostgreSQL

### AI
- LangGraph
- Grok (Provider 1)
- Provider abstraction for Claude, GPT, Gemini
